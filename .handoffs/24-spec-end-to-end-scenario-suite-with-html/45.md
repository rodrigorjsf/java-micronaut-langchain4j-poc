## What was built
- `scripts/check-skill-docs.py` now fails on any skill file (SKILL.md or reference) that points into another skill's directory. It catches four forms: a climbing link (`](../`, `](./../`), a `.claude/skills/<other>/` path, a backticked file name owned only by another skill, and a backticked path qualified with another skill's name. The script header, `README.md`, `docs/06-skills.md` and `docs/INDEX.md` describe the new check.
- Eleven existing cross-skill pointers are now hand-offs by skill name. They were in corpus-retrieval-tests → agentic-evals / writing-retrievable-knowledge, prompt-to-corpus-migration → agentic-codebase-audit, reviewing → authoring-agent-skills, authoring-agent-tools → reviewing, and PROVING-ACTIVATION.md → reviewing. Each hand-off to a user-invoked skill says "ask the user to run it, which they invoke by name".
- All 20 descriptions open with their triggers: "Use when" for model-invoked skills, "Run when" for user-invoked ones. The identity sentence is gone. Where it held the only keyword a turn types, that keyword moved into the triggers. Reach clauses are byte-identical because docs/06 quotes them; the one exception is progressive-tool-disclosure, which gained "which they invoke by name". The ASSEMBLED-EXAMPLE billing description is now triggers, not a noun list.
- Nine over-long skills are split behind scoped references at heading boundaries, with the prose moved verbatim. New files:
  - agentic-tool-boundary: REDIRECTS
  - agentic-evals: NEAR-MISS-HALF, GOLDEN-SET, JUDGE-CALIBRATION
  - gauntlet-loop: UNREACHABLE-BAR, CUTTING-THE-WORK
  - writing-retrievable-knowledge: USER-VOCABULARY, METADATA
  - agentic-codebase-audit: SCORING, RANKING-AND-PLAN, TIME-BOXED-RUN, ARTEFACT
  - prompt-to-corpus-migration: COST, RETRIEVAL-SETTINGS, REMOVAL, RE-RUNS
  - corpus-retrieval-tests: SENTENCE-SOURCES, WHERE-IT-RUNS, CORPUS-GROWTH, REPOSITORY-SUITE (plus content merged into the existing DIAGNOSIS)
  - reviewing-agent-tools-and-skills: PASSES, MERGE-AND-ZERO-CALL, SKILL-OVERLAP-AND-BODIES (plus the routing-set section merged into ROUTING-SET)
  - tool-search-rollout: CENSUS-SCHEMA, DECIDE, APPROVAL-GATE, EXECUTE-AND-VERIFY
  - prompt-injection-layers: TOOL-RESULT-INJECTION
- Every skill now opens with a "| You are here because | Start at |" entry table, and every reference file is linked from it, one level deep.

- **One commit for checker and fixes.** The pointer checker and the 11 pointer fixes landed together (3531bb5), so no commit leaves the script red.

## Learnings
- A section-moving helper that cuts at heading boundaries (skipping fenced code) makes verbatim splits safe. After moving, grep the moved text for "above"/"below".
- `git checkout -- <file>` on a committed file is safe for reverting a scratch red-test line.

## Notes for dependent tickets
- A skill may never name another skill's file. Hand off by skill name; the script fails otherwise, including on `other-skill/FILE.md` in backticks.
- Keep reference file names distinct across skills. `WORKED-EXAMPLE.md` already exists in two skills, and the filename check exempts shared names.
- Sections holding knob sentences checked by `TeachingSkillVocabularyTest` must stay at the paths the test names, or the test's path must move with them.
