## Decisions & deviations
- Report is written by the default-build `KnowledgeBaseTest`, not an `-Pevals` run (spec Testing Decisions says evals profile). Ticket says "each run"; embeddings are in-process, no network. Spec reviewer judged acceptable.
- Query set lives in `src/test/resources/evals/`, not beside the corpus: a test-resources `knowledge/` dir would shadow the corpus on the classpath. Skill text updated to allow this case.
- Negative rows depend on every document in diff mode (competition over the threshold). Displaced positives of other documents are not named; the full set still runs, so they go red in the Queries section. Documented in REPORT.md.
- Only `/retrieval-report.html` added to `.gitignore`; `eval-report.html` left to its own ticket to avoid merge conflicts.
- Schema subset: `id, question, label, expected_source, provenance` (router absent → `routing_input` n/a noted in dataset description).
- Added `queriesCoverTheCorpusBothWays` so an uncovered document fails the build (story 41 purpose), per spec review.
