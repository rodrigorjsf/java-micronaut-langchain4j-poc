## What was built
- `.claude/skills/authoring-agent-skills/SKILL.md` has a new section, "Resources are the third tier, cut by scope". It teaches the following:
  - The three tiers are the description, the body, and resources.
  - References are cut by the path a turn takes, and each one is linked directly from the body's entry table, one level deep.
  - LangChain4j `Skills` loading works like this: every file except `SKILL.md`, `scripts/`, blank files and non-UTF-8 files becomes a `SkillResource`, keyed by a `/`-joined path relative to the skill root. The files are preloaded. `read_skill_resource(skill_name, relative_path)` is registered only when some skill has a resource.
  - The Agent Skills standard's file-read path serves the same body.
  - "The resource path is model-visible text." The path is matched by exact string equality, a miss costs a round trip, and the default `relative_path` description publishes the first resource path from any loaded skill.
- The two-way tool grep now covers resource paths too.
- New section "Hold the draft to writing-great-skills". It inlines four checks: the description holds triggers and no identity sentence, leading words, pruning sentence by sentence, and checkable completion criteria.
- The review table gains row 14 (reference routing) and row 15 (the writing-great-skills pass). The entry table gains two rows.
- New worked example `.claude/skills/authoring-agent-skills/SCOPED-REFERENCES.md`. It shows the `billing` body with an entry table routing to `references/refunds.md` and `references/disputes.md`, both references, why the skill is cut that way, and what is deliberately absent.
