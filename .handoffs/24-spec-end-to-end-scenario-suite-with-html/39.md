## What was built
- **Proven, then fixed.** The tool HTTP client did follow a 302 from a catalogued host to a host outside the catalogue. In the red run, `aRedirectOffTheCatalogueIsNeverRequested` saw the landing route called, and the 169.254.169.254 case hung until the 2 s timeout.
- `ToolHttpClient` now uses its own client, `@Client(id = "tool-apis")`, with `micronaut.http.services.tool-apis.follow-redirects: false`. It follows redirect hops itself:
  - only to an exact catalogue `host:port`
  - never from https to http
  - at most 3 hops
  - with one deadline shared by all hops
- A refused hop comes back as an UPSTREAM_ERROR value and is never retried. The target address is logged for operators and kept out of the model's text.
- `agentic-tool-boundary/SKILL.md` gained two sections: "A redirect is a destination too", under rule 1, and "Side effects wait for a person, between selection and invocation". Both cite primary sources with read dates. The description and the review checklist were extended too.

## Decisions & deviations
- **Validate hops instead of refusing every 3xx**, so an upstream that moved a route (301) keeps working.
- **Exact origin, not registrable domain**: a request is made by this process, and a sibling subdomain is a host nobody reviewed. The port is checked as well.
- **A dedicated client instead of the global `micronaut.http.client.follow-redirects`**. The global switch would have changed `LangfuseScoreWriter`: a 3xx on a score POST would "succeed" with nothing written.
- **The service client inherits the default `max-content-length`.** `aTransportCeilingBelowTheBodyIsNotABudget` still passes, which shows it.
- **Labels.** No `[verified]` labels, because this is a subagent and CLAUDE.md reserves that label for the main thread. The local Micronaut claim is labelled `[sourced — ToolHttpClientTest …]`. The main session may re-run the test and upgrade it.
- **No approval code.** The human-approval section is teaching only. This app's tools are all idempotent GETs, and the skill says so.

## Learnings
- Micronaut `@Client(id=...)` with no url works for absolute-URI requests, and it inherits `micronaut.http.client.*`.
- Micronaut HttpClient follows redirects by default. `follow-redirects` is per client, so scope it with `micronaut.http.services.<id>`.

## Notes for dependent tickets
