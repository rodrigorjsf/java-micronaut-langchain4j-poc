## What was built
- A new user-invoked skill, `.claude/skills/agentic-scenario-suite/`, with `disable-model-invocation: true`. It is portable to any LangChain4j backend, with skills or without.
- `SKILL.md` has four rules that hold on every path:
  - expectations are read off artifacts, and only user inputs may be drafted by a model;
  - every change reaches a human as a reviewed diff;
  - every row records its `source`;
  - existing rows are complemented, never overwritten.
- It then gives 7 steps, each ending on a *Done when* criterion: inventory, domains, input sourcing, draft to the floor, complement, present the diff, run and read.
- A diff mode produces three lists: rows at risk, rows to adjust, and uncovered artifacts.
- `SKILL.md` routes by scope to four references:
  - `INVENTORY.md`: the six artifact kinds, deriving domains, and trace-seeded inputs with paraphrase and anonymisation;
  - `SCENARIO-SCHEMA.md`: the row shape, the kinds, the floor, and where each expectation comes from;
  - `READING-A-RUN.md`: the report reference;
  - `WORKED-EXAMPLE.md`: this repository's paths, identifiers, supported fields, commands and known gaps.
- `docs/06-skills.md` has a table row, an entry with a neighbour table, a Mermaid node in chain 4, "Six skills" by name, and the `agentic-evals` "handed by" row updated.

## Decisions & deviations
- **The report reference is named `READING-A-RUN.md`, not `REPORT.md`.** The harness write guard refuses files named like reports. The content is the report shape the ticket asks for.
- **The description is a trigger sentence ("Run when …"), not a one-line human summary.** The ticket's "description carries triggers, not identity" overrides writing-great-skills' default for user-invoked skills, because it is the more specific requirement.
- **The portable schema documents activation, argument constraints, forbidden tools and call bounds (from spec story 22), hedged "where the runner supports them".** WORKED-EXAMPLE says this runner has only `outcome`/`toolsCalled`. That gap is filed as #52.
- **Guardrails are inventoried as the sixth artifact kind (the spec lists them), but this repository's `ArtifactInventory` has no guardrail kind.** That gap is filed as #53.
- **The skill and the docs/06 row are in one commit.** `check-skill-docs.py` requires both to land together.
- `eval-report.html` is named in portable text because the spec names it as the report file.
