## Decisions & deviations
- **Canonical source.** The entry headings of the PDF, not its at-a-glance page or appendices, which shorten titles with `&`. So ASI02 and ASI03 use "and" and ASI06 keeps "&", exactly as the headings do. ASI05 includes "(RCE)".
- **PDF provenance.** `https://genai.owasp.org/download/52117` returned an HTML gate page. The 57-page PDF I read was a cached copy from another local session's scratchpad (`asi2026.pdf`). Its title page, table of contents and entry headings match what #40 cited.
- **Scope.** The scan covers `.claude/skills` and `docs`. It excludes `.handoffs/`, which are historical records.
- **Where the canonical list lives.** It is in the test, and each skill spells the titles inline. There is no shared list file for skills to point to, because story 54 is removing cross-skill pointers.
- **Rewordings to pass the capital-letter rule.** "ASI09 UI safeguards" became "ASI09's UI safeguards" (docs/03), and "ASI02: `OWASP-COVERAGE.md`" became "ASI02, because" (agentic-codebase-audit SKILL.md).
- **No `scripts/` checker.** The guard is a JUnit test, because the scripts table lives in CLAUDE.md, which this run may not edit.
- **Commits.** One `docs(skills)` commit carries the test and the prose, because the test guards that prose. The review fixes are in a separate commit.

## Notes for dependent tickets
- `TeachingSkillVocabularyTest` fails on any merged text that attaches a non-canonical capitalised title to `ASIxx`, before or after the ID, in `.claude/skills` or `docs`. The canonical list is `TeachingSkillVocabularyTest.CANONICAL_ASI_TITLES`.
- After an `ASIxx` identifier, avoid starting prose with a capitalised word unless it is the title.
- Removing any of the knob sentences listed above fails the knob test. So does renaming a knob in a LangChain4j bump.
